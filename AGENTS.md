# AGENTS.md — Учёт расходов для семьи 

## О проекте
Страница для учёта личных расходов за месяц. Для семьи из троих людей, с телефона и компьютера.
Файлы: index.html — разметка, styles.css — вид, script.js — логика.
Требования к функциям — в папке specs/. Описание для людей — в README.md.

## Правила
- Только HTML, CSS и JavaScript в этой папке. Без npm, библиотек и внешних ресурсов.
- Данные храни в браузере (localStorage). Ничего не отправляй в интернет.
- Интерфейс на русском языке, подписи короткие и понятные.
- Кнопки и поля не меньше 44px, страница работает на телефоне шириной 375px.
- Делай только то, о чём попросили. Работающие функции не ломай.
- После тестов, объязательно делать гит коммит.
- Деньги — целые тенге с пробелами между тысячами: 15 000 ₸. Пустую или неверную сумму не сохраняй и покажи подсказку; никогда не показывай NaN.
- Даты при отображении пользователю показывай
  в формате ДД.ММ.ГГГГ.
- Внутри программы храни даты в формате YYYY-MM-DD.
- При определении текущего дня и месяца
  используй местное время устройства.
  - Границы быстрых периодов «Сутки», «7 дней», «14 дней» и «Месяц» должны соответствовать текущей локальной дате. При смене даты обновляй активный быстрый период автоматически.

## Новая функция
- Каждую новую функцию начинай с файла specs/NNN-nazvanie.md. NNN — следующий номер: 001, 002, 003. Название — латиницей через дефис.
- Разделы файла: Для кого и зачем; Что должно быть; Примеры; Ограничения; Готово, когда.

## Как проверить
- Открыть index.html двойным щелчком.
- Траты 5 000, 2 500 и 12 000 → итог за месяц 19 500 ₸.
- После F5 траты на месте.

## Git
- Коммит и push делаешь ты, но только после моей проверки и моего «да».
- Перед работой выполни git status. Есть незакоммиченные изменения — скажи и спроси, что с ними делать.
- Сделал шаг или файл требований и проверил сам — остановись. Покажи изменённые файлы (git status --short), напиши, что мне проверить руками, и спроси: «Коммитим?»
- «да» значит только коммит, а не следующий шаг. На «да» выполни по очереди: 1) git add . 2) git commit -m "<короткая подпись по-русски>" 3) git push.
- git remote -v пустой — push пропусти и скажи об этом. Push просит upstream — выполни git push -u origin <текущая ветка>. Push отклонён или просит вход — остановись и покажи ошибку целиком.
- Любая команда git не выполнилась — остановись, покажи ошибку целиком и ничего не обходи.
- Я ответил «нет» или описал ошибку — исправь, проверь снова и снова спроси. Без моего «да» не коммить.
- Историю не переписывай: без git reset --hard и git push --force.
