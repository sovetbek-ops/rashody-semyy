# Удаление выбранной траты

## Для кого и зачем
Для семьи, которая ведёт расходы: удалить одну ошибочную или ненужную запись, сохранив остальные траты.

## Что должно быть
- У каждой траты в списке — переключатель для выбора записи. Одновременно можно выбрать только одну трату.
- Рядом с «Итого за период» — кнопка «Удалить». Без выбранной записи кнопка недоступна.
- Перед удалением показать подтверждение с суммой, категорией и датой выбранной траты. Отмена оставляет данные без изменений.
- После подтверждения удалить только выбранную запись, сохранить изменения в localStorage и сразу обновить список, количество записей, итог периода и итог текущего месяца.
- Если есть несколько полностью одинаковых записей, удалить только выбранную, а не все совпадения.
- После успешного удаления снять выбор и показать сообщение «Трата удалена».
- При изменении периода снять выбор, чтобы нельзя было удалить скрытую запись.
- При изменении данных из другой вкладки снять выбор, чтобы он не указывал на другую запись.
- Если список пуст или период некорректен, удаление недоступно.
- Если сохранить удаление не удалось, показать ошибку; запись и итоги должны остаться прежними.
- Уже сохранённые траты должны работать без очистки хранилища.

## Примеры
- В текущем месяце есть 5 000, 2 500 и 12 000 ₸. Выбрать 2 500 ₸ и подтвердить удаление: остаются две записи, итог — «17 000 ₸».
- Нажать «Удалить», затем отменить подтверждение: список и итог не меняются.
- Удалить трату прошлого месяца: она исчезает из списка, итог текущего месяца не меняется.
- Из двух одинаковых трат на 1 000 ₸ выбрать одну и удалить: вторая остаётся.
- После F5 удалённая трата не появляется снова.

## Ограничения
- Кнопка удаляет одну выбранную трату. Массовая очистка, редактирование и отмена уже подтверждённого удаления в эту функцию не входят.
- Только HTML, CSS и JavaScript без библиотек и внешних ресурсов. Данные остаются в localStorage, ничего не отправляется в интернет.
- Интерфейс на русском языке; кнопка и область выбора записи не меньше 44 px. Страница работает на ширине 375 px без горизонтальной прокрутки.
- Существующие добавление, фильтрация, порядок записей и денежный формат сохраняются.
- Код реализации пишется после команды пользователя «делай» для этой функции.

## Готово, когда
- Можно выбрать ровно одну запись; без выбора кнопка «Удалить» недоступна.
- Подтверждение однозначно показывает выбранную трату; отмена ничего не удаляет.
- Удаление 2 500 ₸ из 5 000, 2 500 и 12 000 ₸ даёт «17 000 ₸» и две записи.
- Удаление одной из одинаковых записей сохраняет другую.
- Итоги месяца и периода пересчитываются правильно; удаление траты другого месяца не меняет месячный итог.
- После F5 удалённой записи нет; оставшиеся записи и их порядок сохраняются.
- Смена периода и обновление данных из другой вкладки снимают выбор.
- При ошибке localStorage показана подсказка, запись и итоги остаются прежними.
- После удаления последней записи показаны «0 ₸» и «Пока нет трат»; удаление недоступно.
- Добавление трат 5 000, 2 500 и 12 000 по-прежнему даёт «19 500 ₸»; после F5 данные остаются.
- На ширине 375 px выбор записи и кнопка удобны, горизонтальной прокрутки нет.
